## FLAGSHIP SOFTWARE CONTRIBUTIONS & OPEN-SOURCE ECOSYSTEM

*Ecosystem reach (Nov 2026): ANTsX GitHub organization: 13 repositories, 2,900+ stars, 700+ forks; `ANTsPy` 30,000+ PyPI downloads per month; `ANTs`/`SyN` is a core dependency of fMRIPrep, QSIPrep, Nipype, Clinica, and TemplateFlow.*

- **ANTs (2008–Present):** Advanced Normalization Tools ([github.com/ANTsX/ANTs](https://github.com/ANTsX/ANTs)): C++ library used globally across academia and industry for medical image registration (`SyN`), segmentation (`Atropos`), and cortical thickness; **Creator & Lead Architect**.
- **ANTsPy & ANTsPyNet (2017–Present):** Python interface and deep learning library ([ANTsPy](https://github.com/ANTsX/ANTsPy), [ANTsPyNet](https://github.com/ANTsX/ANTsPyNet)) providing pre-trained 2D/3D networks for brain extraction, Deep Atropos, HippMapp3r, brain age, lesion segmentation, and super-resolution; **Co-Creator & Architect**.
- **ANTsPyMM (2021–Present):** Multi-modal neuroimaging processing and automated QC framework ([ANTsX/ANTsPyMM](https://github.com/ANTsX/ANTsPyMM)) converting structural T1w, FLAIR, rs-fMRI, DTI, and neuromelanin MRI into standardized Image Derived Phenotypes (IDPs); **Lead Architect**.
- **ANTsR (2012–Present):** R statistical programming extension of ANTs ([ANTsX/ANTsR](https://github.com/ANTsX/ANTsR)) featuring `Eigenanatomy`, `SCCAN`, and `SiMLR`; **Creator & Lead Designer**.
- **NSA-Flow (2025–Present):** PyTorch package ([stnava/nsa_flow](https://github.com/stnava/nsa_flow)) implementing Non-Negative Stiefel Approximating Flow for orthogonalish, sparse, interpretable matrix factorization and representation learning; **Creator**.
- **syntx, pysimlr & curvanato (2025–Present):** Next-generation ANTsX tooling in Python: [`syntx`](https://github.com/stnava/syntx) (symmetric normalization transformations), [`pysimlr`](https://github.com/stnava/pysimlr) (similarity-driven linear and nonlinear multi-view reconstruction), and [`curvanato`](https://github.com/stnava/curvanato) (local curvature quantification for anatomical data); **Creator**.
- **subtyper (2023–Present):** Disease subtyping, staging, and latent space evaluation toolkit ([stnava/subtyper](https://github.com/stnava/subtyper)); **Creator**.
- **ITKv4 (2002–Present):** The Insight ToolKit ([itk.org](https://itk.org)): **Lead Designer** for the v4 deformable image registration framework.
- **Neuroconductor (2016–Present):** R platform for reproducible neuroimaging data science ([neuroconductor.org](https://neuroconductor.org)); **Co-Founder & Contributor**.
